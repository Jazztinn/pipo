Installing Pipo on macOS

Pipo is still awaiting Apple notarization. macOS may block the app the first time you open it and warn that it cannot be verified or may be potentially harmful. This is expected for the current release.

If macOS blocks Pipo

  1. 1

    Download Pipo, then try to open it.

  2. 2

    Open System Settings.

  3. 3

    Select Privacy & Security.

  4. 4

    Scroll down to the message about Pipo.

  5. 5

    Click Open Anyway.

  6. 6

    Confirm Open if macOS asks again.

About your Mac password

macOS may request your login password when authorizing Pipo or granting a system permission. This prompt comes from macOS. Pipo cannot receive, transmit, or store your password.

Enter it only in an authentic macOS system dialog. Pipo will never ask for your Mac password inside the app or this website. Any other permission request will explain what feature needs it.
